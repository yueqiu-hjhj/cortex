# Cortex 使用手册

> 适用版本 1.0.36。面向"一个人、一台电脑、要认真学完几门课"的使用方式。
> 所有功能都在本地数据库里，不依赖账号；联网只在你主动触发的动作里发生。

---

## 0. 它适合什么，不适合什么

**适合**：把课件/论文/网课变成可检索的知识库；学完要记住（复习排期 + 掌握度）；写综述要能过审（证据链 + 撤稿检查）；每天要知道"现在该做什么"。

**不适合**：多人协作、手机随时问答、团队知识库。这三件事它主动不做（见 §8）。

---

## 1. 安装与第一次打开

1. 运行 `Cortex_1.0.36_x64-setup.exe`。没有代码签名，Windows 会提示"未知发布者"→ 更多信息 → 仍要运行。
2. 首次启动会建库并跑迁移（几十毫秒）。
3. **先配模型**：设置 → 模型。
   - **在线**：填 provider 的 Base URL + API Key，选模型名。聊天、材料生成、嵌入可以分别配。
   - **本地**：Ollama / LM Studio，填 `http://127.0.0.1:11434` 这类地址。
   - 没有模型时，聊天和生成会直接报错——这是最常见的"打不开"原因。
4. 数据位置：应用数据目录下的 `cortex.db`（SQLite）。笔记另有 Markdown 文件（vault）。

> 想完全离线：设置 → 数据与隐私 → 打开离线模式。它会拒绝所有联网调用（含 web 搜索、连接器、agent 的 web 工具）。

---

## 2. 五分钟上手（完整闭环）

1. **建科目**：仪表盘 → 新建科目（如"线性代数"）。科目下可以再建主题。
2. **导入资料**：科目 → 添加资料 → 选 PDF/DOCX/PPTX/EPUB/图片/音频，或贴一个网页/YouTube 链接，或直接粘贴文本。
   导入后会自动分块、嵌入。看到"分块数 > 0"才算成功。
3. **提问**：聊天 → 选科目 → 问一个只有这份资料能回答的问题。回答下方是引用，点开能回到原文位置。
4. **生成材料**：材料 → 生成 → 选"速查表"或"闪卡"。生成的闪卡可以直接进复习队列。
5. **复习**：今天 → 复习队列 → 逐张评分（Again/Hard/Good/Easy）。评分决定下次出现时间（FSRS）。
6. **计划**：计划 → 建目标（带截止日期）→ 粘贴长期计划 → 拆成周任务 → 选周次 → 自动排期。

跑完这 6 步，你就用到了它 80% 的价值。

---

## 3. 每日循环

| 时间 | 打开 | 做什么 |
|---|---|---|
| 早上 | **今天** | 看今日计划块、待复习卡片、到期任务；用输入框快速记一笔 |
| 学习时 | **计划 / 番茄钟** | 按块执行，番茄钟计时；完成的块会记录实际用时 |
| 学完 | **笔记 / 材料** | 把想留下的写成笔记；需要时生成速查表 |
| 晚上 | **计划 → 收尾** | 未完成的：复制到明天 / 标记跳过 / 留原位 |
| 每周 | **实验室 → 检索评测** | 显式跑一次，和上次同配置对比；超过 30 天自检会提醒 |

## 4. 功能详解

### 4.1 仪表盘

科目卡片墙 + 学习 streak。键盘 `j`/`k` 或方向键移动焦点，回车进入。
用途：一眼看到"哪门课最近没碰"。

### 4.2 科目与主题

- **科目**是最大的容器：资料、笔记、卡片、考试、目标都挂在它下面。
- **主题**是科目内的细分（如"特征值"）。检索、掌握度、排期都能按主题过滤。
- 删除科目会先把整行数据 + 附件落到 `.deleted-<id>-<时间戳>` 恢复目录，再物理删除。

### 4.3 导入资料

| 来源 | 说明 |
|---|---|
| PDF / DOCX / PPTX / XLSX / EPUB | 文本层直接抽取；扫描件走视觉 OCR |
| 图片 | OCR（需要视觉模型） |
| 音频 | 转录（本地 WhisperX 或配置的转录服务） |
| 网页 / YouTube 链接 | 抓正文入库 |
| 粘贴文本 | 直接作为一个来源 |

注意：
- 导入是异步的，状态从 `pending` → `ready`；失败会在来源上显示原因。
- 分块有字符偏移，引用能精确回到原文；重新索引后旧引用仍可"重锚"。

### 4.4 阅读器与摘录

打开来源 → 阅读 → 选中文本 → 摘录。摘录带页码/位置，之后可以直接进综述草稿或变成复习卡。
右侧可以写批注；批注和摘录都会进知识图谱。

### 4.5 笔记与 AI 提案

- 笔记是 Markdown，同时存在数据库（索引）和 vault 文件（可读、可 Git）。
- **AI 不能直接写你的笔记**：agent 用 `propose_note` 提交草稿，进入"待确认提案"，你点「采纳并写入」才落库。提案是 diff 形式，能看到改了什么。
- 采纳时如果笔记在这期间被改过，会要求二次确认（防止覆盖你的手改）。

### 4.6 聊天与导师

- **Scope 三态**：只用笔记 / 笔记+网络 / **不检索**（纯模型回答）。第三态会显示「未检索」徽章——它诚实地告诉你"这段没有依据"。
- **多来源**：可以勾选多个来源，只在它们里面检索。
- **引用**：每条引用带冻结快照；源文本变了可以重锚；模型编造的引用会被丢弃并记录。
- **共享线程**：切换 agent 时勾"继续此线程"，之前的消息都是上下文。
- **导师（Tutor）**：按掌握度出题/讲解，难度随 BKT 掌握度调整。

### 4.7 学习材料生成

七种：速查表、闪卡、测验、音频概览、信息图、思维导图、幻灯片（另有视频概览）。
流程：选科目/来源 → 选类型 → 生成大纲 → 逐页确认或改写 → 生成。
注意：
- 生成需要文本模型；图片/音频另需对应槽位的模型。
- 生成的闪卡不会自动进队列，要在材料页点"加入复习"。

### 4.8 复习

- 算法：FSRS（间隔重复），评分 Again/Hard/Good/Easy。
- 来源：生成的闪卡、手动卡片、Anki `.apkg` 导入。
- 导出：Anki `.apkg`，可以带去手机。
- 「今天」页只显示到期的，不显示"以后再说"的。

### 4.9 考试模式

建一场限时考试（选主题、题量、时长）→ 作答 → 自动评分 → 错题进复盘。
考试结果会更新主题掌握度，进而影响复习队列和导师难度。

### 4.10 计划

四层，从上到下：

1. **目标**：标题 + 截止日期（+ 可选绑定科目）。
2. **长期计划**：在目标上粘贴 4–52 周的计划原文，填周数；「拆成周任务」用模型按周打标签（每条 30–180 分钟、每周≤8 条、只取原文）。
3. **周次**：顶部选"目标 + 第 N 周"，网格切到那一周；「自动排期」只排这一周，不会借别的周的任务。
4. **时间块**：拖拽调整时间/时长；完成块记录实际用时，用于校准下次的预估（"你过去 60 天平均要花 1.4 倍预估时间"）。

配套：番茄钟（白噪音、阶段跳过）、日历同步（Google，双向：完成的移除、拖动的时间回写）、看板（按状态分组）。

### 4.11 科研

| 功能 | 位置 | 说明 |
|---|---|---|
| 文献发现 | 科研 → 文献 | 关键词或一句话研究问题，检索 arXiv/PubMed/OpenAlex |
| 阅读器 | 文献 → 打开 | 原文 + 摘录 + 批注 |
| PRISMA 8 维 | 科研 → 综述 | 研究问题/方法/贡献/结果/局限/适用人群/限制/复现成本，每值必须带 verbatim 证据句 |
| 撤稿与期刊信号 | 命令行 `cortex-paper-meta` | 撤稿三形态、OA 全文、DOAJ/core 期刊信号；结果在论文列表显示角标 |
| 复现清单 | 科研 → 实验 | 从方法部分生成环境/数据/超参/验证/坑 |
| 归档 | 设置 → 导出 | `.cortex-pkg`（可迁移的完整包） |

### 4.12 智能体

**是什么**：会自己多步调工具、全程留痕的助手。和聊天不同，它有一组工具、一个权限档、一个步数上限。

**权限档（累计，从低到高）**：

| 档 | 能用什么 |
|---|---|
| read | 列科目、检索知识库、读来源、搜笔记、看主题树、读笔记 |
| write | + 建笔记、存闪卡、改笔记、提交提案 |
| network | + 联网搜索、读网页、MCP 工具 |
| files | + 工作目录内读/写/改/列/搜文件 |
| shell | + 白名单命令（`run_command`） |

**工具（17 个）**：`list_notebooks`、`search_notebook`、`get_source`、`search_notes`、`get_knowledge_tree`、`get_note`、`save_note`、`update_note`、`save_flashcards`、`propose_note`、`web_search`、`fetch_page`、`read_file`、`write_file`、`edit_file`、`list_dir`、`search_files`、`run_command`、`delegate`。

**三种用法**：

1. **预置角色**（最快）：智能体页 → 预置角色 → 一键创建。有知识库管家、综述学者、复现工程师、推导陪练、章节写手、外联研究员、代码助手。
2. **自己建**：名称 + 系统提示词 + 勾技能 + 勾工具 + 选权限 + 步数。
3. **委派**：给 agent 勾 `delegate`，它就能把子任务交给另一个 agent。规则：**子 agent 权限不能高于父**、不能委派给自己、最多 2 层、每次运行最多 3 个子任务。子任务在运行列表显示「↳ 子任务」。

**文件工具**：先在智能体页顶部设「工作目录」。所有路径都被限制在这个目录内（`..` 和符号链接都逃不出去）。

**命令执行**：权限选 shell + 在「命令白名单」里填前缀（如 `cargo test`、`python`）。不起 shell，`; | & > <` 这类元字符直接拒绝，所以白名单前缀不能被串联。默认空白名单 = 完全禁用。

**技能**：可复用的工作方式。内置 4 个模板；可以导出成 `.cortex-skill.json`（带版本与来源）带到另一台机器，导入时同名必须确认覆盖。

### 4.13 实验室

- **回答健康度**：把"无引用/引用失效/被降级/编造丢弃"分开统计。
- **引用台账**：每一条冻结引用的状态，可重锚修复。
- **检索评测**：4 种模式对比（关键词/向量/混合/重排），只和**上次同配置**的运行对比；超过 30 天启动自检会提醒，但不会自动跑（它要花时间和额度）。

### 4.14 分析与成长

学习热力图、每科掌握度（BKT）、知识图谱（概念之间的关系）、成长曲线。
用途：判断"哪一章其实没学会"，而不是"看了多久"。

### 4.15 英语与词汇

- 精读：六种训练模式（逐句、翻译、复述等）。
- 词汇本：手动添加或从材料采词；带定义与例句。
- 写作工具箱：从你采纳过的修改里生长出的个人规则。

### 4.16 录音与转录

桌面端可以直接录音并转录（需要本地 WhisperX 服务）；iOS 端录音后通过 live sync 回传。
转录结果作为普通来源入库，走同一套分块/检索。

### 4.17 设置

| 分组 | 关键项 |
|---|---|
| 模型 | 每个槽位（聊天/材料/嵌入/视觉/转录）分别配 |
| 数据与隐私 | 离线模式、遥测、导出数据库 |
| 同步 | 自托管 syncd 地址与凭据（加密存储） |
| 备份 | age 加密 + rclone 远端 |
| MCP | 注册 server，同步工具；agent 勾选后可用 |
| 定时任务 | AI 提示词 / 连接器同步 / 长期计划排期 |

## 5. 数据、备份与迁移

- **主库**：`cortex.db`（SQLite）。**笔记正文**：vault 里的 `.md`。
- **备份**：设置 → 备份（age 加密），或直接复制 `cortex.db`（应用关闭时）。
- **整库加密**：命令行 `cortex-vault seal` / `open`（应用关闭时使用；口令丢失无法恢复）。
- **迁移到另一台机器**：设置 → 导出 `.cortex-pkg`，在新机器导入；或直接带走 `cortex.db` + vault。
- **导出到别的工具**：Anki `.apkg`、Obsidian 目录、Markdown/CSV/XMind。

## 7. 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 聊天/生成报"没有模型" | 设置 → 模型里对应槽位没配 |
| 导入后检索不到 | 来源状态不是 ready；或嵌入模型换了导致向量空间不一致（设置里能看到分块空间分布，需要重新索引） |
| 引用显示"已失效" | 源文本变了；在引用台账里点重锚 |
| 回答没有引用 | scope 选了"不检索"，或检索没命中；看「未检索」徽章与检索元数据 |
| 同步失败 | syncd 没起 / 地址或凭据错 / 代理拦截 |
| 代理 502 | 网络代理间歇性故障，重试即可（本机经验：等 30–60 秒） |
| 命令执行报"未配置白名单" | 智能体页 → 命令白名单，每行一个前缀 |
| 委派被拒 | 子 agent 权限高于父，或层级/数量到上限 |
| vault 打不开 | 口令错误（无法恢复）；确认 `.vault` 文件完好 |

## 8. 能力边界（诚实表）

| 能力 | 状态 |
|---|---|
| 本地知识库 + 检索 + 引用 | ✅ |
| 复习排期（FSRS）+ 掌握度（BKT） | ✅ |
| 材料生成（7 种） | ✅ |
| 系统综述（PRISMA + 证据链） | ✅ |
| 智能体（工具/权限/提案/委派/命令） | ✅ |
| 多端 | 桌面 + iOS 录音；**无手机聊天端** |
| 多人协作 | ❌ 单用户 |
| 命令隔离 | 白名单 + 无 shell，**不是容器沙箱** |
| 自动更新 | 安装包未签名，**不支持** |
| 手机端离线复习 | 通过 Anki `.apkg` 导出间接支持 |

---

## 9. 一句话总结

**导入要干净，提问要带 scope，生成要进复习，计划要落到块。** 这四件事做到，它就是一个能陪你学完一门课的工具；只当聊天用，它和别的聊天没区别。
